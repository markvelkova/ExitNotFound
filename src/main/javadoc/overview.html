Exit Not Found

Overview

Exit Not Found is a text-based adventure with basic game mechanics, and simple persistence. The player explores a grid-like map, discovers items and a goal (the exit door), and must manage health while navigating hazards.

Implementation Summary

The implementation uses an explicit map model that stores tile types and optional top-level objects. Players are represented by a Player object tracking position, facing direction, health and game state. Commands are parsed into a small command model and dispatched to action implementations, which encapsulate behaviour such as movement, displaying the map, or saving/loading. Persistence is provided via Java serialization for a simple, versioned game state snapshot.

Main Components and Packages

  • game — core engine and game loop coordinating phases and player input.
  • maputils — map model, tile and top-object interfaces, factories and utilities for parsing/printing maps.
  • actions — concrete action implementations invoked by commands.
  • commands — parsing, validation and help text for user commands.
  • toolkit — helpers for saving/loading game state and other utilities.
  • ui — message repository and simple I/O adapters used by the engine.

How to run the game

mvn exec:java

The game will start in the console, and you can interact with it using text commands. The default map used for new games is specified in mapa.txt file and can be changed using the symbols defined in maputils/GameSymbols.java. The first line defines number of collumns, the second number of rows.

How to regenerate the API documentation

mvn clean javadoc:javadoc

The generated documentation will appear under target/site/apidocs.
